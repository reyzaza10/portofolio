Tentang saya

Mengenal perjalanan saya, mulai dari pengalaman, ketertarikan di bidang teknologi dan data, hingga visi saya dalam mengembangkan karier profesional.

Projects

Data Analysis Database Management Business Intelligence
Analisis Data Peserta Pelatihan & Penempatan Kerja ke Jepang
Studi Kasus: LPK Osin
Proyek analisis data end-to-end yang berfokus pada pengolahan dan analisis data peserta pelatihan serta penempatan kerja ke Jepang dengan studi kasus LPK Osin.

Mencakup perancangan database relasional menggunakan PostgreSQL, pembuatan dan pengolahan data simulasi, penyusunan query SQL untuk analisis, hingga pengembangan dashboard interaktif menggunakan Power BI untuk menghasilkan insight yang mendukung pemahaman proses bisnis.

Proyek ini berawal dari tugas mata kuliah Basis Data, terinspirasi dari kunjungan ke stan LPK Osin pada kegiatan Jobfair kampus, kemudian dikembangkan secara mandiri.
PostgreSQL SQL Power BI pgAdmin
Database Design
  • Merancang database relasional dengan 8 tabel.
  • Mengimplementasikan Primary Key dan Foreign Key.
  • Merepresentasikan proses bisnis pelatihan hingga keberangkatan peserta.
SQL Data Analysis
  • Menggunakan JOIN untuk menghubungkan tabel.
  • Menggunakan GROUP BY dan HAVING.
  • Menggunakan fungsi agregasi untuk menghasilkan informasi analitis.
Interactive Dashboard
  • 6 visualisasi utama: distribusi program, skema pembayaran, tren bulanan, pendidikan peserta, mitra perusahaan, dan funnel keberhasilan.
  • Slicer interaktif berdasarkan program dan rentang tanggal pendaftaran.
Key Insights
  • Tokutei Ginou menjadi program dengan jumlah peminat tertinggi.
  • Skema dana talangan menjadi pilihan mayoritas peserta.
  • Tren pendaftaran meningkat pada periode Mei–Desember.
  • Fuji Food Processing menjadi perusahaan mitra dengan jumlah penempatan peserta terbesar.

* Seluruh data peserta dan transaksi dalam proyek ini merupakan data simulasi/fiktif untuk keperluan pembelajaran dan analisis. Proyek ini tidak menggunakan data internal LPK Osin yang sebenarnya.
